# Alpha Lab statistical method audit

Date: 2026-10-20  
Scope: repository source, tests, research notes, dependency declarations, and recent commits. This is a code audit, not a new calibration study.

## Executive findings

- The repository does **not** contain `estimated_phi`, `oracle_phi`, `oracle_exact`, or `VarRatio` implementation or stored calibration output in its Python, Markdown, or JSON files. The supplied 4.10% / 3.90% / 16.20% rates are therefore treated as external historical evidence; the generating process, statistic, parameter fit, and original test cannot be independently audited here. Keep `estimated_phi` blocked and preserve the cited result outside any regenerated artifacts.
- Alpha Lab has custom moving-block bootstrap and Bartlett HAC code. The cross-sectional calibration report records that every compared MBB/HAC/IID procedure failed its prespecified Type-I and coverage requirements. `cs-time-block-centered-v1` is already diagnostic-only; it must remain blocked for formal verdicts.
- Time-series MBB and the RankIC bootstrap have deterministic and limited regression tests, but no accepted calibration report establishing valid formal p-values over the actual dependent/overlapping-label use cases. Their results can remain useful diagnostics and historical reproductions; they are not eligible for new formal verdicts.
- The current verdict function has no method-status input. The time-series path can therefore turn an uncalibrated interval and adjusted p-value into `SUPPORTED` or `REJECTED`; this is a governance defect even though the cross-sectional store has a separate closed verdict gate.
- SciPy is a declared dependency and exposes a maintained Benjamini–Hochberg / Benjamini–Yekutieli implementation. The project reimplements BH. `statsmodels`, `arch`, and `linearmodels` are neither declared dependencies nor installed in the research environment checked for this audit.
- Fama–MacBeth, White Reality Check, and Hansen SPA are not implemented. Nested Walk-Forward is not a statistical inference method; the repository has walk-forward evaluation, but no nested model-selection protocol that fully separates repeated tuning from a final untouched test set.

| `evaluation/ic.py` Pearson IC and Spearman RankIC | Measures linear association and monotone rank association; SciPy `pearsonr` / `spearmanr` are direct mature implementations. | Uses SciPy for point estimates and returns no p-value. | Appropriate as descriptive point estimates on aligned observations. ## Method-level conclusions

1. **No Fama–MacBeth implementation exists.** The current cross-sectional flow reports per-section IC and summarizes across time. Introducing Fama–MacBeth would change the estimand and is not justified as a RankIC patch.
2. **No `estimated_phi` source or artifact is available.** The stated 16.20% Type-I result cannot be traced to a code defect versus estimator uncertainty or violated assumptions from this checkout. Preserve the result as a blocker; do not run a parameter search.
3. **Do not promote the current bootstrap/HAC variants.** The existing cross-sectional calibration is decisive against the tested configurations. The small time-series smoke tests are not enough to establish a formal error rate.
4. **The directly reusable function is p-value adjustment.** SciPy's implementation can replace BH and provide BY. That only changes correction computation; BH/BY require valid marginal p-values and a declared testing family.
5. **No broad refactor or new dependency is justified in this pass.** The available, verified SciPy dependency is sufficient for the p-adjustment replacement. Since `statsmodels`/`arch` are absent, HAC and block-bootstrap outputs remain diagnostic rather than adding an unverified runtime dependency.

## Minimal change plan

1. Delegate BH/BY adjustment to SciPy and add numerical equivalence tests against SciPy; retain Holm with known-value tests.
2. Add a versioned method registry and make formal verdict evaluation fail closed unless a method is explicitly `PASS`. Current uncalibrated MBB/HAC/estimated-phi methods are not `PASS`.
3. Preserve existing inference formulas, historical artifacts, and method IDs; update the protocol/version and frozen manifest only after tests pass.
4. Document scenario states and Alpha Lab capability gaps. Do not run another large Monte Carlo search or change thresholds.

- [SciPy `spearmanr`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html): descriptive coefficient and caution that its p-value is accurate only for large samples; it does not model this project's time dependence.
- [statsmodels `cov_hac`](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html): mature Newey–West covariance implementation, considered but not installed/declared here.
- [arch `StationaryBootstrap`](https://arch.readthedocs.io/en/stable/bootstrap/generated/arch.bootstrap.StationaryBootstrap.html): mature stationary-bootstrap resampler with random block lengths; considered but not installed/declared here.
- [linearmodels Fama–MacBeth](https://bashtage.github.io/linearmodels/panel/panel/linearmodels.panel.model.FamaMacBeth.html): mature panel-regression implementation with kernel covariance options; not a substitute for RankIC.
