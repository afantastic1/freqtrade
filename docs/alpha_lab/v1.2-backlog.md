# Alpha Lab v1.2 Backlog

Deferred items only. None of these items is required to reinterpret v1.1 evidence, and none should be started as an unbounded research-core refactor. Each change that affects a frozen interface requires an `ENGINE_CHANGE_REQUEST`, versioned identity, regression evidence, and Maintainer review.

1. **New statistical methods** — develop an independent calibration design, preregister data-generating scenarios and acceptance limits, validate size/coverage/power, preserve all existing method IDs and statuses, and only then propose a new method version.
2. **Additional factor operators** — define narrow declarative schemas, deterministic engine-owned implementations, availability/missingness contracts, identity hashes, and security/leakage tests before admission.
3. **Multi-period joint features** — specify point-in-time alignment, label horizon interactions, missing-period behavior, and identity semantics; validate without accessing held-out data.
4. **Fundamental PIT data review** — obtain source-vintage and row-level release/revision evidence for snapshots, audit dataset catalogs, and pass strict PIT validation before use.
5. **Strategy backtest integration** — define causal execution timing, fees, slippage, funding, universe, and out-of-sample separation before connecting research Evidence to strategy performance.
6. **Advanced ML** — defer model families and selection procedures until data boundaries, nested validation, multiple-testing control, and model identity are independently specified and reviewed.
